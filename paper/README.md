# The paper draft

The full research paper draft is an editable document in your Claude account:

**"Which rare diseases hide from diagnosis? A network analysis of diagnosability across 12,866 diseases"**

Sections: Abstract, 1 Introduction, 2 Related work, 3 Data, 4 Methods, 5 Results (5.1-5.8), 6 Discussion, 7 Limitations, 8 Conclusion, References.

## To get a Word / PDF / Markdown copy
Open the doc and use its export / download option (Word, PDF or Markdown).

## Before you submit
1. **Insert the figures.** The Results section names each figure file in brackets, for example `[4_percolation.png]`. Insert them from the `figures/` folder of this project.
2. **Check every reference.** The reference list was written from memory and not looked up: verify authors, years, volumes and pages, and add the closest papers your own Google Scholar search finds. Suggested searches: `phenotype similarity rare disease diagnosis network`, `disease symptom bipartite network percolation`, `diagnostic ambiguity phenotypic overlap HPO`.
3. **Check the numbers against `results/summary.md`.** Every number in the paper comes from a full run with seed 42; if you change `config.py` and re-run, update the paper.
4. **Read the Limitations section and be ready to defend it** (see `docs/VIVA_QA.md`).
5. **Write the final text in your own words.** The draft is a starting point; you must understand and be able to explain every sentence.
